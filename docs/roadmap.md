# 开发计划

按“先能用、再补全”的顺序排。工作量是粗略估算（按一名熟悉 TG 协议的 Go 开发计），会随实际进展调整。

## 阶段 0：跑通开源版（当前）

- [x] 导入 Teamgram Server，编译通过
- [ ] 用 docker compose 起齐依赖（MySQL、Redis、etcd、Kafka、MinIO），跑通私聊和普通群
- [ ] 编译 teamgram-android，连上自己的服务端
- [ ] 修复上游失败的测试（见 `server/UPSTREAM.md`）

## 阶段 1：登录、品牌、后台基础（约 1.5 个月）

- [ ] 邮箱 + 用户名登录，手机号可选；短信接自有网关（可插拔）
- [ ] 安卓、iOS 换名称、图标、配色，去掉所有 Telegram 标识
- [ ] 后台第一版：管理员账号与 RBAC、操作审计、用户管理（封禁 / 禁言 / 强制下线）、群管理、全局配置

## 阶段 2：频道与超级群（约 2 到 3 个月）

- [ ] 频道：公开 / 私有、广播、阅读数、评论区
- [ ] 超级群：上万成员、细分管理员权限、慢速模式、话题
- [ ] 后台：频道与超级群管理、认证标识、公开搜索屏蔽

## 阶段 3：离线推送（约 0.5 到 1 个月）

- [ ] iOS APNs：签名账号与 .p8 密钥管理，按设备所属账号路由
- [ ] 安卓：自有长连接保活优化 + UnifiedPush
- [ ] 后台：签名账号管理页、推送到达率统计

## 阶段 4：体验功能（约 1 到 2 个月）

- [ ] 贴纸、消息反应、主题与壁纸、定时消息、自动删除
- [ ] 两步验证密码、秘密聊天

## 阶段 5：音视频（约 3 到 6 个月）

- [ ] 一对一语音 / 视频通话（自建中继，兼容 TG 客户端通话协议）
- [ ] 群语音、视频会议

## 阶段 6：开放平台（约 2 到 3 个月）

- [ ] 机器人 API
- [ ] 小程序

## 贯穿始终

- 多数据中心与就近接入（GeoDNS、多接入地址、自建代理），全球可用
- 监控告警：Prometheus + Grafana
- 内容安全：本地敏感词库、举报处理、自部署识别模型
